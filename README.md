## 📋 Sobre o Projeto

Site completo para a **Casas Pinheirão**, empresa especializada em casas pré-fabricadas de madeira e alvenaria em Curitiba, Pinhais e região metropolitana do Paraná.

### 🎯 Funcionalidades Principais

- ✅ **Design Responsivo** - Mobile-first e totalmente adaptável
- ✅ **Galeria Interativa** - 15 casas com preços e pop-ups detalhados
- ✅ **FAQ Acordeão** - 5 perguntas frequentes sobre casas pré-fabricadas
- ✅ **Integração WhatsApp** - Formulários e botões diretos para WhatsApp
- ✅ **Facebook Widget** - Últimas postagens da página oficial
- ✅ **SEO Otimizado** - Meta tags, Schema markup e sitemap completo
- ✅ **CTAs de Conversão** - Botões estratégicos para gerar leads
- ✅ **Vídeos Integrados** - YouTube embeds responsivos

### 🛠️ Tecnologias Utilizadas

- **HTML5** - Estrutura semântica
- **CSS3** - Flexbox, Grid, Animações CSS
- **JavaScript** - Vanilla JS para interatividade
- **Bootstrap 5** - Framework CSS responsivo
- **Font Awesome** - Ícones profissionais
- **Google Fonts** - Tipografia otimizada

## 🚀 Como Usar

### Opção 1 - GitHub Pages (Gratuito)
1. Fork este repositório
2. Vá em **Settings** → **Pages**
3. Selecione **Deploy from a branch** → **main**
4. Seu site estará em: `https://seuusuario.github.io/casas-pinheirao-site`

### Opção 2 - Netlify (Recomendado)
1. Conecte este repositório ao [Netlify](https://netlify.com)
2. Deploy automático a cada commit
3. Domínio personalizado gratuito
4. HTTPS automático

### Opção 3 - Vercel
1. Conecte ao [Vercel](https://vercel.com)
2. Deploy instantâneo
3. Performance otimizada
4. Analytics incluído

### Opção 4 - Hospedagem Tradicional
1. Baixe todos os arquivos
2. Faça upload via FTP para seu servidor
3. Configure domínio para https://casaspinheirao.site/parana/

## 🔧 Manutenção

### Adicionar Nova Casa na Galeria
1. Adicione imagem em `assets/images/galeria/`
2. Crie novo card na seção gallery
3. Adicione modal correspondente
4. Teste responsividade

### Atualizar Preços
1. Localize seção "Promoção de Casas"
2. Atualize valores nos cards
3. Atualize também nos modais
4. Teste links do WhatsApp

### Modificar FAQ
1. Localize seção FAQ
2. Edite perguntas/respostas no acordeão
3. Mantenha estrutura Bootstrap
4. Teste funcionalidade mobile
